📦 INSTALLATION
───────────────────────────────────────────────────────────────────────
1. cd gmail-to-sheets
2. pip install -r requirements.txt

🔧 SETUP (One-time)
───────────────────────────────────────────────────────────────────────
1. Enable Gmail API + Sheets API in Google Cloud Console
2. Download OAuth credentials → save as credentials/credentials.json
3. Create Google Sheet → copy Spreadsheet ID
4. Edit config.py → set SPREADSHEET_ID = 'your_id_here'

🚀 RUN
───────────────────────────────────────────────────────────────────────
python src/main.py

First run: Browser opens for OAuth → Grant permissions
Subsequent runs: Uses saved token.json (no browser)

✅ WHAT IT DOES
───────────────────────────────────────────────────────────────────────
1. ✓ Fetches unread emails from Gmail Inbox
2. ✓ Extracts: From, Subject, Date, Content
3. ✓ Appends to Google Sheets (new rows)
4. ✓ Marks emails as READ in Gmail
5. ✓ Saves state (prevents duplicates)
6. ✓ Safe to re-run (no reprocessing)

📁 KEY FILES
───────────────────────────────────────────────────────────────────────
config.py               → Edit: SPREADSHEET_ID
credentials/credentials.json → Add: OAuth credentials (from Google)
credentials/token.json  → Auto-generated after first run
processed_ids.json      → Auto-generated (tracks processed emails)

src/main.py             → Main script (run this)
src/gmail_service.py    → Gmail operations
src/email_parser.py     → Email parsing
src/sheets_service.py   → Sheets operations

⚙️ CUSTOMIZATION
───────────────────────────────────────────────────────────────────────
Edit config.py:

# Filter by subject

❓ TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────
Problem: "credentials.json not found"
Fix: Place credentials.json in credentials/ folder

Problem: "SPREADSHEET_ID not configured"
Fix: Edit config.py with your actual Sheet ID

Problem: "Access not configured"
Fix: Enable Gmail + Sheets APIs in Google Cloud Console

Problem: Token expired
Fix: Delete token.json and re-run (re-authenticate)
